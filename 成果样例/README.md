# 成果样例 / Sample Outputs

这里放的是**几本书的导出效果演示**（网页格式），可以直接双击打开看。

## 说明

- **每本仅抽取 12 条**，只为演示排版效果，**不是完整内容**。
- 书籍内容的著作权归原作者与出版方所有。本目录**仅供演示导出格式之用**，
  请勿将其用于传播、分发或任何商业用途。
- 想自己导出完整内容，用软件或命令行跑一次即可：

```bash
python src/weread_hotmarks.py "活着" --all --fmt html
```
